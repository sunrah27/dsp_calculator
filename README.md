## About
Very simple crafting calculator that will give you what items you need when trying to craft an item. It supports a limited set of resipes which will be expanded in future updates. This is an early version and not sure if everything is working perfectly. I have included an inventory option which will make it easier to determine what items you need without having to carry around excess items.
